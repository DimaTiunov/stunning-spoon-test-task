# Задание

## Контекст

Это приложение `promo` для Webasyst: клиент применяет промокод в личном кабинете, сотрудник просматривает промокоды в бэкенде. Код сгенерировал AI-ассистент по задаче «сделай приложение промокодов». В прод он ещё не попадал.

Проект работает на **старой версии Webasyst**, поэтому решения должны использовать только стабильный API фреймворка без новых возможностей.

Твоя задача: **подготовить код к мержу**.

## Бизнес-требования

1. Применять промокод и видеть свои использования могут **только авторизованные** клиенты.
2. Клиент видит **только свои** использования промокодов.
3. Один промокод один клиент может применить **не более одного раза**.
4. Промокод нельзя применить **после даты окончания** и **сверх лимита** использований (`max_uses`), даже при двух одновременных запросах.
5. Сотрудник видит промокоды в бэкенде **только с правом «Просмотр промокодов»**.
6. Деньги (минимальная сумма заказа, скидка) хранятся и считаются **в копейках** (целые числа).

## Что нужно сделать

- Найти и исправить проблемы в PHP-коде, шаблоне и JS.
- Привести код в соответствие с бизнес-требованиями.
- Объяснить, как ты проверишь, что исправления работают.

Всё за 25 минут сделать не обязательно. Расставь приоритеты: начни с самого важного.

## Правила

- Можно и нужно пользоваться **Claude Code, Codex** или другим AI-инструментом, которым ты обычно работаешь.
- Покажи экран с терминалом и окном агента.
- Проговаривай вслух, что делаешь и почему.
